# Rovia — Make every day count.

Offline-first Android routine planner and to-do app (Kotlin, Jetpack Compose, Material 3, Room).

## Build the APK on GitHub
1. Push this repo to GitHub (branch `main`).
2. Open the **Actions** tab, then the latest **Android CI** run (or click **Run workflow**).
3. When it turns green, scroll to **Artifacts** and download `rovia-debug-apk`.
4. Unzip it and install `app-debug.apk` on your phone (allow "install unknown apps" when asked).

## Status (v0.1.0)
Implemented: splash + welcome, Today dashboard, tasks (add, complete, delete with undo, search, filters), Room storage, light/dark theme.
Not yet implemented: planner/routines, habits, calendar, focus timer, notes, insights, notifications, settings, export/import.
